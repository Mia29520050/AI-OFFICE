# Analysis skill
1. Separate facts, assumptions, hypotheses and recommendations.
2. Trace conclusions to the supplied evidence; identify missing inputs.
3. Compare options against explicit criteria and constraints.
4. Consider failure modes, resource limits, compatibility and reversibility.
5. Do not invent measurements, benchmarks, standards or sources.
6. Label estimates as estimates and state how they could be validated.
7. Finish with findings, confidence, risks and the next test.
